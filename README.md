# Synheart Homebrew tap

Homebrew packages for [Synheart](https://synheart.ai) tools, on macOS and Linux.

## Synheart CLI

```bash
brew tap synheart-ai/tap
brew trust synheart-ai/tap      # Homebrew 7+ loads formulae only from trusted taps
brew install synheart
```

Upgrade with `brew upgrade synheart`. The CLI knows it was installed this way:
`synheart update` points you at `brew upgrade` instead of replacing the binary.

Hooks written by `synheart guard install` and `synheart life connect` point at
Homebrew's stable `synheart` link, so they keep working across upgrades. If you
used the install script before, remove that copy so only one `synheart` is on
your PATH, then run `synheart guard install --write` again.

The formula is published from the first release that records that stable link.
Until then, use the install script: `curl -fsSL https://synheart.sh/install | sh`.

## How this tap is updated

`Formula/synheart.rb` is generated by Synheart's release pipeline and pushed
here after each release's archives are on `https://dist.synheart.ai`, which the
formula downloads from. Don't edit it by hand: the next release overwrites it.
