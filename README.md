# Synheart Homebrew tap

Homebrew packages for [Synheart](https://synheart.ai) tools.

## Synheart CLI

```bash
brew install synheart-ai/tap/synheart
```

Upgrade with `brew upgrade synheart`. The CLI knows it was installed this way:
`synheart update` points you at `brew upgrade` instead of replacing the binary.

After installing or upgrading, hooks written by `synheart guard install` and
`synheart life connect` point at Homebrew's stable `synheart` link, so they keep
working across upgrades.

## How this tap is updated

Casks in `Casks/` are generated by the CLI's release pipeline (GoReleaser) and
pushed here after each release's binaries are published to
`https://dist.synheart.ai`. Don't edit them by hand: the next release overwrites
them.
